# 🏀 坤时转换器 · 下班倒计时

> 小黑子的专属计时器 —— 距离下班的每一秒，都在「坤」之中。

一个**零依赖、单文件**的下班倒计时网页。默认展示「我」和「熊老师」两张卡片，人物信息（昵称、头像、称号、上下班时间、卡片配色）全部可自定义，配置保存在浏览器本地，刷新不丢。

## 功能特性

- ⏱ 实时倒计时：距离各自下班时间还有 `HH:MM:SS`
- 🐔 坤时换算：`坤时 = 剩余秒数 ÷ (坤时比例 × 3600)`，默认 1 坤时 = 2.5 小时
- 👥 多人物卡片：默认「我」（🧑‍💻 17:30）与「熊老师」（🐻 18:00），可自由增删
- ⚙️ 自定义配置：昵称、备注称号、头像 emoji、上班时间、下班时间、卡片配色
- 📊 在岗进度条：按每个人自己的上下班时段计算当日进度
- 🎉 下班彩带：某人到达下班时间的瞬间自动撒彩带，卡片切换为「已下班」
- 💬 自动段子：文案随剩余时间（很远 / 过半 / 临近 / 已下班）自动切换
- 🕐 标签页标题同步：未下班时显示最近一个人的剩余时间
- 🌙 跨夜班次支持：下班时间早于上班时间时按次日计算，并标注「（跨夜）」
- 💾 配置持久化：`localStorage` 自动保存，支持导出 / 导入 JSON

## 快速开始

直接用浏览器打开 `index.html` 即可（无需构建、无需安装依赖）。

如果想用本地服务器：

```bash
# Python
python -m http.server 8080
# Node
npx serve .
```

然后访问 `http://localhost:8080`。

## 自定义人物

点击页面上的 **⚙️ 自定义人物**，在弹窗中可配置：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 头像 | 任意 emoji（输入框带常用 emoji 候选） | `🧑‍💻` `🐻` `🐔` |
| 昵称 | 显示在卡片标题，留空自动填「打工人 N」 | `我`、`熊老师` |
| 备注/称号 | 昵称右侧的小标签，可留空 | `卑微打工人`、`卷王本王` |
| 上班时间 | 用于计算在岗进度条 | `09:00` |
| 下班时间 | 倒计时目标时刻 | `17:30` |
| 卡片配色 | 7 种预设渐变：石墨灰 / 番茄红 / 紫罗兰 / 森林绿 / 深海蓝 / 土豪金 / 樱花粉 | `slate` |

底部还可设置：

- **1 坤时 = 多少小时**：默认 `2.5`，范围 0.1 ~ 24
- **默认配色**：新增人物时使用的默认主题

弹窗底部的其他按钮：

- `＋ 添加一位打工人`：新增卡片（人数不限，页面自动换行）
- `⬇️ 导出配置` / `⬆️ 导入配置`：备份或迁移 `kun-time-config.json`
- `恢复默认`：回到「我 17:30 + 熊老师 18:00」

点击 **💾 保存并应用** 立即生效并写入本地存储；`Esc` 或点击遮罩可关闭弹窗。

## 默认配置

```json
{
  "kunRatio": 2.5,
  "defaultTheme": "slate",
  "people": [
    { "emoji": "🧑‍💻", "name": "我",     "tag": "卑微打工人", "start": "09:00", "off": "17:30", "theme": "slate"  },
    { "emoji": "🐻",   "name": "熊老师", "tag": "卷王本王",   "start": "09:00", "off": "18:00", "theme": "tomato" }
  ]
}
```

存储位置：`localStorage['kun-time-config-v1']`。清除浏览器数据或点击「恢复默认」即可回到该配置。

## 换算公式

```
1 坤时 = 2.5 小时 = 9000 秒
坤时   = 距离下班剩余秒数 ÷ (2.5 × 3600)
```

坤时归零 = 快乐拉满。🎉
